# Firefox 115.0 для Linux x86-64

Тот же браузер, что основной на хосте разработки, — чтобы проверять
просмотрщик и проверочную страницу в одинаковом движке. В репозитории лежит
частями по 45 МБ (у GitHub предел 100 МБ на файл), суммы — в `SHA256SUMS`.

```sh
tools/firefox/install.sh            # в /opt/ff115/firefox
tools/firefox/install.sh ~/ff115    # или в свой каталог
```

Скрипт проверяет суммы частей и собранного архива и распаковывает его.

Без дисплея Firefox снимает скриншот так:

```sh
/opt/ff115/firefox/firefox --headless --no-remote --profile "$(mktemp -d)" \
  --window-size=760,760 --screenshot /tmp/page.png http://localhost:8740/
```

Первый запуск с новым профилем иногда не успевает создать снимок;
повторный запуск его создаёт. В режиме без дисплея WebGL2 недоступен.
