# Документация Wormlisp

Главная копия документации — здесь. Документ правится в том же коммите, что и
код, который он описывает, поэтому по истории git видно, какой версии
документа соответствует какой код.

| Документ | Что в нём |
| --- | --- |
| [design.md](design.md) | Модель: биология, тело, мышцы, нервное управление, среда, численная схема, валидация, риски |
| [architecture.md](architecture.md) | Устройство программы: процессы, модули, кодогенерация, решатель, сервер, форматы, тесты, журнал решений |
| [plan.md](plan.md) | Этапы работ с условиями готовности и итогами |
| [parameters.md](parameters.md) | Значения параметров с источниками и степенью достоверности |

Формулы записаны блоками `math` (LaTeX), схемы — блоками `mermaid`; GitHub
отрисовывает и то и другое.

До 16.10.2026 документы велись в Claude Docs; там остались замороженные копии
с пометкой о переносе.
